# Systemsteuerung von Creative OS

Seiten: Netzwerk (WLAN, Kabel), Bildschirme (Anordnen per Ziehen, Auflösung, Hz, Skalierung,
Ausrichtung, Hauptbildschirm – mit 15-Sekunden-Rückfrage wie bei Windows), Ton (Ausgabe/Eingabe,
Lautstärke), Drucker (Standard, Testseite, hinzufügen), Darstellung (Hintergrundbild, gilt sofort),
Software & Updates (rpm-ostree), System (Gerätename, Hardware).

Starten: `creative-settings [--page bildschirme|netzwerk|ton|drucker|darstellung|updates|system]`
Ausprobieren: `./run-dev.sh` · Installieren: `sudo ./install.sh`

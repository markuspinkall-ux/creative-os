# Orbit TV

Fire-TV-App (Android TV) im Orbit-OS-Look (Graphit/Porzellan).

- **Sender:** Das Erste, ZDF, die Dritten und weitere öffentlich-rechtliche Programme direkt.
  Die Stream-Adressen werden beim Start aus der freien Zapp-Schnittstelle (MediathekView) aktualisiert.
- **Eigene Sender:** ☰ → „Neuer Sender …“ oder Kachel „＋ Sender hinzufügen“: Name und Adresse
  (M3U, M3U8 oder direkter Stream) eintragen. Wird auf dem Gerät gespeichert.
- **Ordnen:** ☰ auf einer Kachel → Favorit, Gruppe zuordnen (auch neue Gruppen), Verschieben, Ausblenden;
  eigene Sender zusätzlich Bearbeiten und Löschen.
- **Bedienung:** OK ansehen · im Bild ▲▼ umschalten · OK oder Zurück → Übersicht · 0–9 Senderplatz.

Installation: App „Downloader“ auf dem Fire TV, Adresse
`https://github.com/markuspinkall-ux/creative-os/releases/download/orbit-tv/OrbitTV.apk`.
Geht auf Fire-TV-Geräten mit Fire OS; die neuesten Sticks mit Vega OS können keine APKs installieren.

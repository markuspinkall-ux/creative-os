# Creative Calculator

Der Rechner von Creative OS im Graphit-Look.

- Rechnet exakt (0,1 + 0,2 = 0,3), deutsch mit Komma, Punkt vor Strich, Klammern
- Prozent wie bei Windows: 200 + 10 % = 220
- Wurzel, Quadrat, Kehrwert, Vorzeichen
- Live-Vorschau des Ergebnisses beim Tippen
- Verlauf (Uhr-Symbol oder Strg+H) – ein Klick holt ein Ergebnis zurück
- Tastatur: Ziffern, + − * /, Enter, Rücktaste, Esc; Strg+C kopiert, Strg+V fügt ein

# Creative Shots

Bildschirmfotos für Creative OS – aufgebaut wie das Snipping Tool von Windows 11, im Graphit-Look.

- **Druck-Taste** oder **Win + Umschalt + S**: Bildschirm wird eingefroren, oben die Leiste mit
  Rechteck, Fenster, Vollbild und Freihand (Tasten 1–4, Esc bricht ab)
- Das Foto landet automatisch in der Zwischenablage und unter „Bilder › Bildschirmfotos“
- **Editor:** Kugelschreiber, Textmarker, Pfeil, Rechteck, Radierer, Zuschneiden, Rückgängig/Wiederholen,
  Farben und Strichstärke, Kopieren, Speichern, Speichern unter, In Creative Pictures öffnen
- **Neu** mit Verzögerung (3, 5, 10 Sekunden), z. B. für geöffnete Menüs

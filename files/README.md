# Dateien – der Dateimanager von Creative OS

Graphit-Design, so einfach wie der Windows-Explorer – und so gebaut, dass man nichts kaputt machen kann:

- **Nichts wird überschrieben.** Gibt es einen Namen schon, entsteht „Name (2).ext“.
- **Löschen = Papierkorb.** Endgültig gelöscht wird nur über „Papierkorb leeren“ mit Rückfrage.
- **Alles rückgängig:** Kopieren, Verschieben, Umbenennen, Neuer Ordner und Löschen (Strg+Z oder Knopf im Hinweis).
- **Dieser PC:** Ordner, Festplatten und USB-Sticks mit freiem Platz; USB-Sticks mit einem Klick auswerfen.

Tastenkürzel wie bei Windows: Strg+C/X/V, Strg+Z, Strg+A, F2, Entf, Enter, Alt+Enter, Alt+←/→, Rücktaste, F5, Strg+F, Strg+Umschalt+N.

Ausprobieren: `./run-dev.sh [Ordner]` · Installieren: `sudo ./install.sh`

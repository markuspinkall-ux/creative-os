# Creative Pictures

Bildbetrachter von Creative OS – aufgebaut wie „Fotos“ bei Windows 11, im Graphit-Look.

- **Sammlung:** alle Bilder aus Bilder (mit Unterordnern), Downloads und Schreibtisch, nach Monaten; Favoriten; Ordner
- **Ansicht:** Zoom (Mausrad, Doppelklick, Regler), Verschieben, Pfeile und Filmstreifen zum Blättern
- **Aktionen:** Drehen (wird gespeichert, Fotodaten bleiben), Favorit, Löschen (Papierkorb), Kopieren,
  Als Hintergrundbild, Umbenennen, Im Ordner zeigen, Diashow (F5), Vollbild (F11)
- **Infos:** Aufnahmedatum, Abmessungen, Größe, Kamera, Belichtung
- Formate: JPEG, PNG, GIF (bewegt), WebP, BMP, TIFF, SVG, HEIC, AVIF, JPEG XL

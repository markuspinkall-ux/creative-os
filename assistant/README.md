# Sprachassistent

Sitzt als Mikrofon-Symbol im Tray. Aktivieren: „Computer“ sagen oder aufs Symbol klicken.

- **Wetter:** „Wie wird das Wetter morgen?“, „Regnet es heute in Hamburg?“ (Open-Meteo, ohne Konto)
- **Timer:** „Timer auf 10 Minuten“, „Wie lange läuft der Timer noch?“, „Timer stoppen“
- **Musik:** „Spiele Bohemian Rhapsody von Queen“ – sucht und spielt im offiziellen YouTube-Music-Player (im Creative Player);
  „Pause“, „Weiter“, „Lauter“, „Leiser“, „Nächstes Lied“, „Stopp“
- **Uhrzeit/Datum:** „Wie spät ist es?“, „Welcher Tag ist heute?“

Rechtsklick aufs Symbol: Mikrofon wählen, Stimme wählen (Piper: Thorsten, Kerstin, Ramona, Eva,
Karlsson), Aktivierungswort an/aus, Wohnort fürs Wetter.

Datenschutz: Aktivierungswort (Vosk) und Spracherkennung (faster-whisper) laufen komplett auf dem PC.
Ins Internet gehen nur die Wetter-Abfrage und die YouTube-Suche.
